# house SDLC public pages — v1 (retired)

These three pages (markdown source + rendered HTML) described the **v1** process: `process.{md,html}`
(the v1 loop, its gates and reviews), `best-practices.{md,html}` (the token-economics theory), and
`case-study.{md,html}` (that theory applied to the `dev-command-center` → skills refactor).

The process they describe was **retired at the 2026-07-29 cutover** — see
[ADR-0004](../../docs/adr/0004-house2-coexistence-and-advisory-hooks.md), which designated that cutover
as the end of the coexistence window. The **pages** were retired from the published site on
**2026-07-29 at owner call**, because a site that still served them was publishing a process the repo no
longer runs.

They are superseded on the live site by [`docs/index.html`](../../docs/index.html), the quickstart
([`docs/quickstart.md`](../../docs/quickstart.md) + its mirror `docs/quickstart.html`), and the current
process narrative ([`docs/process-v2.md`](../../docs/process-v2.md) + its mirror `docs/process.html`,
which deliberately takes over this archived page's URL so old links land on current truth).

Their relative links to each other still resolve — the three moved together. Links out to the wider
repo are v1-era and are not maintained.

Nothing was deleted. Archive, never erase.
